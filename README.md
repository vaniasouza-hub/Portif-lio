## Como o Projeto Funciona
O site é uma página única dividida em partes:
* **Menu no topo:** Leva direto para as seções do site ao clicar.
* **Banner (Carrossel):** Mostra 3 imagens principais que passam automaticamente ou pelas setas.
* **Perfil:** Mostra minha foto, um resumo sobre mim, meus objetivos e as ferramentas que eu uso.
* **Projetos:** Mostra 3 cards com os trabalhos que eu já fiz.
* **Contato:** Tem botões para mandar e-mail e acessar meu GitHub e LinkedIn.
